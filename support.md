# Support — Assets Exporter for Jira Service Management

## Contact us

Email **support@sixwiki.com** — we aim to respond within one business day.

To speed up diagnosis, please include:

- your schema's approximate object type count and object count,
- the issue key you exported to,
- what you expected and what happened instead.

## Before you write

The [documentation](index.html) covers setup, usage and troubleshooting,
including the two most common issues:

- **Export fails with a permissions error** — if your Assets object schema
  restricts access via its Roles configuration, add the app under the schema's
  roles (Schema settings → Roles).
- **A reference shows a key but there is no sheet for it** — the reference
  points at an object in a different schema; the Overview sheet counts these.
